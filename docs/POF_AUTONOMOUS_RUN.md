# POF Autonomous Completion Run

Started under founder mandate to complete the remaining Principles of Flight explanation-visual system autonomously.

Rules for this run:

- Preserve locked Batch 1 assets unless a genuine technical defect is found.
- New learning visuals are raster only (PNG master + WebP web asset where practical).
- Do not bake a PilotVault banner into new learning images; branding belongs in the website UI.
- Work in batches of at most five visual concepts.
- Reuse a visual only where the same concept genuinely explains the mapped question.
- Use the approved POF handbook as technical source of truth.
- Branch/preview before production, verify live rendering, then lock.
- On connection errors, verify remote state before retrying any write.
